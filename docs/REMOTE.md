# 手机与远程访问

在设置中打开「手机与远程访问」，填写将要使用的 HTTPS origin（例如 `https://my-computer.example.ts.net`），再开启。网关只监听 `127.0.0.1:8801`，不会绑定公网；主服务的 8799 端口仍只用于本机。应用重启后远程网关保持关闭，所有配对和会话失效。

通过已经安装并登录的 Tailscale，可在本机设置：

```sh
tailscale serve --bg http://127.0.0.1:8801
```

也可使用 HTTPS 反向代理，必须保留浏览器的原始 Host，且只转发 8801 端口。桌面设置的 origin 必须与浏览器地址完全一致，包括非默认端口；不要转发 8799、8800。网关不信任 X-Forwarded-Host，也不接受来自其他 Origin 的请求。此仓库不会自动安装 Tailscale、修改网络配置或公开端口。

点击「配对新设备」，勾选允许设备访问的伙伴，再生成配对码。设备在上述 HTTPS 地址输入配对码后，可查看这些伙伴的主对话记录并发送消息。远程发送沿用伙伴的工具审批模式；Ask 模式的请求需要在桌面处理。自动编辑或完全自动模式仍按原策略执行，因此只应授权可信设备使用这些伙伴。

配对码为随机十位数字，有效期五分钟、单次使用，连续五次错误后失效。新码替换上一个未使用码。配对 cookie 使用 Secure、HttpOnly、SameSite=Strict，24 小时过期。会话仅驻内存，关闭网关或撤销所有设备后失效。设备不能取得本地服务 bearer、修改设置、批准工具、删除 Bot 或管理凭据。页面仅显示纯文本，并每 2.5 秒刷新当前对话；不包含桌面工具卡片、附件、群聊和语音功能。

本地自动测试覆盖 origin、配对范围、重用与撤销、过期和尝试次数限制。实际手机、Tailscale 账号及 HTTPS 证书链需要在部署环境验收。
