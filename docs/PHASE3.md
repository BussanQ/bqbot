# 阶段 3：聊天、频道与线程

## Bot 管理

侧栏 Bot 的右键菜单提供置顶、标为未读、编辑资料、复制、复制会话 ID、隐藏和删除。头像可使用 emoji 或简短文字。隐藏只影响列表显示，可以在侧栏重新显示；删除会清理 Bot 的会话数据，并从频道成员中移除它。

复制创建新的 Bot ID、会话和工作目录，保留引擎、模型、人设及头像等资料。原 Bot 的聊天记录、原生会话游标和转交会话不会复制。重复复制会生成不同的名称。

## 多个对话线程

每个 Bot 保留原有主对话，还可创建独立线程。每个线程有独立 transcript 和原生引擎会话，在侧栏显示于对应 Bot 下方。关闭线程会取消相关工作并保留历史，搜索仍能找到已关闭线程中的内容；主对话不能关闭。

阶段 1、2 的主聊天和转交记录会自动登记为线程，原 NDJSON 文件保持原位。每个“目标 Bot × 提问 Bot”的转交线程可直接查看；关闭后再转交会创建新线程，也可以在私人转交的 `ask_bot` 参数中指定 `thread: "new"`，保留旧线程并从新的会话开始。

`ask_bot` 现在先返回受理结果，提问方无需在工具调用中等待目标模型。目标完成后，服务把结果作为后续消息交给原提问方，自动启动一次续答。续答和被转交的轮次不能再次派发，仍保持阶段 2 的单层转交限制。停止、关闭或删除相关对话会取消任务及待续答，避免停止后又出现回复。正在执行的任务不跨服务重启恢复。

MCP 新增：

- `list_threads`：列出当前 grant 可见的线程。
- `close_thread`：关闭可见的非活动线程。
- `list_room_targets`：列出当前频道中可转交的其他成员。

权限 grant 仍按轮次生成，审批专用 grant 不提供这些管理工具。

## 频道

频道拥有自己的共享聊天记录、成员名单、共享指令和工作目录。可使用数据目录内自动创建的工作目录，也可指定已存在的绝对路径；删除频道不会删除用户指定的目录。

- **Lead**：没有明确提及时，由指定 lead 回复。
- **@提及**：使用 `@名字` 或 `@Bot ID` 指定频道成员；明确提及优先于自动选择，多个提及可以分别排队。
- **Auto**：决策模型从频道成员中选择一个回复者。未配置、缺少密钥、超时、请求失败或返回结果不明确时，回落到 lead。

每个 Bot 的频道会话与其私人聊天隔离。频道轮次使用共享 transcript 构建上下文，包含其他成员的发言和频道指令，不复用私人聊天游标。同一工作目录内的 Pi 进程依次执行，以免覆盖彼此的 MCP grant 配置；等待过程支持取消。

决策模型设置包含 API Base URL、模型 ID 和密钥环境变量名称。默认地址为 `https://openrouter.ai/api/v1`，默认环境变量为 `OPENROUTER_API_KEY`。密钥由服务进程从环境读取，设置文件和界面只保存变量名。需要在启动应用或 `bqbot serve` 的环境中提供该变量。

## 记忆、压缩和搜索

记忆是用户维护的会话备注。线程和频道分别保存备注；发送消息时按关键词和时间从本地召回有限数量的记忆，加入该轮上下文，不调用外部检索服务。

线程可手动压缩上下文：保留最近 12 条记录供完整重放，把更早的消息保存为有长度上限的文本摘录，并清空旧的原生会话游标，使下一轮从压缩上下文继续。摘录是有损的本地压缩，不是模型生成的语义摘要；完整 transcript 始终保留，不受压缩影响。正在运行或排队中的线程不能压缩。

全文搜索按不区分大小写的文本匹配，覆盖主对话、独立线程、转交线程和频道，包括已关闭线程。返回最近的最多 100 条匹配，可以跳转到原会话。

## 数据与兼容

在原有 `bots.json`、`threads/*.ndjson` 和 `handoffs/` 基础上增加：

- `threads/index.json`：线程资料、独立会话游标、关闭状态和压缩摘录。
- `threads/conversations/<线程 ID>.ndjson`：新建独立线程的记录。
- `rooms.json`、`rooms/<频道 ID>.ndjson`：频道资料与共享记录。
- `memories/<会话 ID>.json`：该线程或频道的记忆。
- `decision.json`：决策模型地址、模型 ID 和密钥环境变量名。

数据文件采用 `0600` 权限。桌面端仍仅通过本地 HTTP + SSE 服务访问数据。接口客户端见 `internal/service/phase3_client.go`。

## 验证范围

存储使用临时目录；调度、频道、转交与 UI 使用 Echo 或模拟驱动；Auto 决策使用本机 HTTP 模拟服务验证路由和回落。不会在自动化测试中向 OpenRouter 或其他提供商发送真实请求。

本机产物的 HTTP 冒烟测试验证线程隔离、频道 @提及、搜索和记忆、复制和关闭，以及服务重启后的记录保留。视觉验收截图保存在忽略的 `build/shots/`。
